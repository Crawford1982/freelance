# SEO CTR + Conversion Optimisation Summary

## Context
- **GSC Data (6 months to 4 Oct 2026):** 355 clicks / 64.2k impressions / 0.6% CTR / position 11.7
- **Problem:** High impressions but very weak CTR indicates titles/metas aren't compelling enough
- **Goal:** Rewrite for UK freelancer day rate / take-home calculator intent

---

## Homepage (index.html)

**BEFORE:**
```
Freelance Rate Calculator UK — Hourly, Day Rate & Pricing Tool
```

**AFTER:**

**Why:** More specific to search intent, action-oriented, speaks to user need (take-home pay vs generic "pricing tool")

## Conversion Improvements

### Results Panel CTA (New)
Added prominent save/download CTA button inside the results panel:
```html
<button class="...">
  <icon>download</icon>
  <span>Save Your Results as PDF</span>
</button>
<p class="text-xs">Free — saves locally, no account needed</p>
```

**Why:** Captures calculated results as lead retention mechanism, uses existing Print to PDF functionality, reduces friction with clear "no account needed" messaging

### Header Button
**BEFORE:**
```
Print Report
```

**AFTER:**
```
Save as PDF
```

**Why:** Clearer value proposition, more obvious what the button does, stronger conversion language

---

## Key Improvements

1. **More Specific Titles:** "Work Out Your Take-Home Pay" vs generic "Pricing Tool"
2. **UK Positioning:** Led with "UK" in all titles for better geographic targeting
3. **Action-Oriented:** "Calculate", "Work Out" instead of passive descriptions
4. **Benefit Focus:** "rates you can actually live on", "minimum day rate", "take-home pay"
5. **Conversion Path:** Prominent save CTA using existing functionality
6. **Less Keyword Stuffing:** Removed awkward "freelance rate calculator (UK)" phrasing
7. **Consistent Messaging:** Aligned titles, metas, and on-page copy

---

## Expected Impact

- **CTR:** Should improve from 0.6% baseline due to more compelling, specific titles
- **Conversion:** Prominent save CTA should increase engagement and return visits
- **Rankings:** More specific targeting may improve relevance for "UK freelancer day rate" queries
- **UX:** Clearer value propositions throughout the funnel
